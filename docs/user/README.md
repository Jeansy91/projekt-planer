# User Guide

Projekt-Planer is an interactive project planner with a Gantt chart and a swimlane view. Projects are stored in your browser, in a local file or in the cloud, where you can share them with others.

- [Getting started](getting-started.md): storage modes, the first project and the layout of the interface
- [Gantt chart](gantt.md): create, move, resize and select tasks
- [Swimlane view](swimlane.md): lanes, the staging row and moving tasks between lanes
- [Teams](teams.md): create, rename, reorder and collapse teams
- [Zoom & density](zoom-density.md): visible time range and row height
- [Undo / redo](undo-redo.md): history and activity log
- [Import / export](import-export.md): JSON files and the File System mode
- [Collaboration](collaboration.md): cloud projects, invitations and roles
- [Settings](settings.md): profile, theme, security and account
- [Shortcuts](shortcuts.md): keyboard shortcuts and mouse gestures

## Storage modes

| Mode | Where the data lives | Account needed | Shareable |
|---|---|---|---|
| **Browser** | LocalStorage of your browser | No | Via export |
| **File** | A JSON file on your disk (File System Access API) | No | Via the file |
| **Cloud** | Supabase | Yes | Yes |

All changes are saved automatically.
