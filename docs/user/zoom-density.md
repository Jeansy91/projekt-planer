# Zoom & Density

Adjust the timeline and row height to your needs. Zoom controls the visible time range, density controls the vertical compactness.

## Zoom (Visible Range)

Zoom determines how many weeks are visible on the timeline at once. A smaller value shows more detail; a larger value gives more overview.

### Zoom levels

| Display  | Visible range              |
|----------|----------------------------|
| 8 weeks  | ~2 months – maximum detail |
| 12 weeks | ~3 months                  |
| 16 weeks | ~4 months                  |
| 20 weeks | ~5 months                  |
| 26 weeks | ~½ year                    |
| 52 weeks | 1 year – full overview     |

### Changing zoom

- **Dropdown:** Click the zoom dropdown in the calendar header and select a level.
- **Mouse wheel:** Hold Ctrl and scroll (Windows/Linux) or ⌘+Scroll (Mac).

**Note:** The zoom setting is saved with the project and restored on next open.

## Navigating the timeline

Hold Shift and scroll (Windows) or ⇧+Scroll (Mac) to pan the timeline left or right without zooming.

Use the **Previous week** / **Next week** arrows in the calendar header to shift week by week. The **Today** button jumps to the current week.

## Row Height (Density)

Row height controls the vertical compactness of task rows. Three levels are available:

| Level           | Description                           | Best for             |
|-----------------|---------------------------------------|----------------------|
| **Comfortable** | Largest row height, plenty of space   | Few tasks, desktop   |
| **Compact**     | Medium row height                     | Standard view        |
| **Dense**       | Smallest row height, maximum overview | Many tasks, overview |

### Changing density

- **Dropdown:** Click the density dropdown in the calendar header and select a level.
- **Mouse wheel:** Hold Shift and scroll without Ctrl – cycles through density levels.

**Tip:** The density setting can also be set as default in [Settings](settings.md).
